Ảnh ChatGPT vẽ (một hàng khung, hoặc lô gộp nhiều hàng) → tệp hu-<tên>.sprite.json cho game Linh Khí
Quái Anh hùng · Người làng Vũ khí · Đồ · Vật phẩm Hiệu ứng Ghép đồ Giao diện Phòng Làng

1Chọn hiệu ứng và lấy prompt vẽ

Xem prompt
Sửa thông số (chỉ khi Claude dặn)

Dán prompt vào ChatGPT. ChatGPT chỉ cần vẽ một tấm ảnh (một hàng khung từ trái sang phải), rồi bạn lưu ảnh đó về máy.

2Đưa ảnh ChatGPT vẽ vào đây

Bấm để chọn ảnh, kéo thả ảnh vào, hoặc dán (Ctrl+V)
Ảnh một hàng khung như prompt, nền một màu trơn (đúng màu prompt ghi).

Khung vàng là từng khung công cụ tìm được, số ở góc là thứ tự. Chạm vào khung nào để bỏ khung đó (khung đỏ gạch chéo, ví dụ khung thừa, bảng phụ); chạm lại để lấy lại. Ảnh có phần thừa (chữ, bảng màu) thì cắt bớt:

3Kiểm tra và tải file

Đang tách cho: . Xem hiệu ứng chạy trên nền game bên dưới, đúng ý thì mới tải.

Nền xem:

    Gửi file .sprite.json cho Claude để đưa vào game (thư mục game/art/custom).
