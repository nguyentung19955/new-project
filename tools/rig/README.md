Rig đã chỉnh tay của tool dựng xương (`tools/dung-xuong.html` → nút **Lưu rig .json**), mỗi file `<mã>.json`:
khớp xương (toạ độ trên ảnh đã tách nền), vùng bộ phận (nén RLE), loại vũ khí, tay cầm, biên độ.
Thả file `.json` cùng ảnh vào tool (hoặc **Nạp rig…**) để dựng lại đúng như lần trước. Xem `docs/HUONG-DAN-DUNG-XUONG.md`.
