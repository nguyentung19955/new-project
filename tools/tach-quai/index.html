Tách Sprite Quái

Ảnh ChatGPT vẽ → tệp .sprite.json cho game Linh Khí
Xưởng Sprite

1Chọn quái và lấy prompt vẽ

Xem prompt
Sửa thông số (chỉ khi Claude dặn)

Dán prompt vào ChatGPT. ChatGPT chỉ cần vẽ một tấm ảnh, rồi bạn lưu ảnh đó về máy.

2Đưa ảnh ChatGPT vẽ vào đây

Bấm để chọn ảnh, kéo thả ảnh vào, hoặc dán (Ctrl+V)
Ảnh lưới 8 cột × 6 hàng như prompt. Nền ô cờ, nền trắng hay trong suốt đều được.

Khung vàng là từng hình công cụ tìm được, số "hàng.khung" ở góc. Nếu ảnh có phần thừa (bảng chữ, khung giải thích) thì cắt bớt:

3Kiểm tra và tải file

    Gửi file .sprite.json cho Claude để đưa vào game.
