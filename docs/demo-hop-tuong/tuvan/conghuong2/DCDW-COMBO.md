## Bộ bài nổi tiếng (tiprelay, https://tiprelay.com/데스티니-차일드-디펜스워-덱-추천-조합-정리/)
- **다비:** 다비 + 샤마시 + 베리트 + 모아 + 오로라밈킹.
- **제거티:** 제거티 + 샤마시 + 오로라밈/자르라밈 + 모아/베리트 + 멀린.
- **워울프:** 멀린 + 샤마시 + 오로라밈킹 + 키리누스.
- **코스밈:** 코스밈 + 샤마시 + 오로라밈 + 키리누스 (+ 베리트 / 프레이야 / 네반). Bàn 2★ toàn 코스밈 thắng bộ 제거티 và 다비 (DC#2161).
- **자청비:** cho 자청비 ăn 오로라밈킹 (Moa quá chậm).
- **Chậm:** 이미르 + 리자/마야우엘 + 잔다르크 + 오로라밈 · **Độc:** 아텐 + 언노운.
- Không tìm thấy danh sách "combo không chạy".

## Rút ra cho game mình
1. Copycat giữ **dạng** (thức tỉnh / vàng) và **buff trên thân** (Aurora) → làm theo (DC#16750).
2. Teleporter là cách xếp bingo Railgun → bingo phải cập nhật ngay sau đổi chỗ (đã đúng).
3. Đá "chỉ chiếm ô" (không phải Child) → không tính bingo / chuỗi cùng loại (suy từ nguồn ô đá).
4. Chỗ **chưa rõ** (Aurora King lên ụ đặc biệt, Mimic + Berit, giữ thức tỉnh khi ghép, Mad Clown) → **giữ luật cũ**, chỉ làm cho nhất quán + chữ rõ.
