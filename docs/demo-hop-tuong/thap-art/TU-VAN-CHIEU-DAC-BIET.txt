TURRET MERGE — SIGNATURE MOMENTS
31 Legendary + Mythic Turret Skill Showcases
Art/Implementation Brief | 2026-11-05 | English

GOAL
Every high-tier turret should have an immediately recognizable "I know what just happened" beat, not a larger ordinary bullet. Each entry below specifies: (1) a 0.6–1.5 second visual sequence with timed beats, (2) an optional modest gameplay twist and whether it affects balance, (3) an exact asset sheet name with named sprite groups, animation frames and target sizes, (4) one concise art-generation prompt, and (5) image-only implementation. These are visual event lengths, NOT changes to any existing multi-second active durations. Most mechanics are optional and require balance testing.

REFERENCE ART STYLE AND NON-NEGOTIABLE RENDER CONTRACT
Reference: provided TURRET MERGE CO-OP screenshot — 5x3 top-down mini turret heads on industrial gunmetal board, enemy path to left, cores on right. New assets must echo the head's exact motifs, metal material, turret colors and dark cartoon outline. All generated source sheets have perfectly flat solid MAGENTA #FF00FF between isolated cells and sprites. No baked letters, damage numbers, UI, grid frames, cast shadows or bloom that disappears into chroma key. Remove magenta into genuine alpha OFFLINE at asset preparation time; preserve smooth edges and avoid halos. One sheet per turret here; groups within a sheet are independent pieces for reuse. Except where noted, target source cells are 256x256 or 192x192; actual on-screen render is typically 48–160 CSS px depending on enemy and signature emphasis. A sprite sheet with a 1x8 hand animation consists of eight square frames, not a single continuous illustration.

Allowed renderer operations: drawImage from pre-created transparent PNG (including atlas frame crop), translate, rotate, scale, flip, tint and opacity; flipbook frame selection; layer/anchor transforms; optionally adjust already-existing sprite position, animation speed, or visibility. NO canvas strokes, no code-drawn lines/shapes, procedural particles, gradients, circles, paths, canvas shadows, live SVG VFX, or procedural shaders. A textured beam/tether is a PNG transformed between endpoints, NEVER a stroked line. Rendering text/numeric HUD is allowed outside VFX; don't bake text into art.

Animation semantics: use absolute world/lane anchors and a path-coordinate timeline. Easing is interpolation of sprite transforms, not visible vector drawing. Preload atlases. Use deterministic seeded cosmetics so CO-OP/PVP peers can reproduce the same action; gameplay state is server/authoritative simulation, VFX-only client. In enemy crowding, cap one large showcase at a time per side, prioritize active mythics and first-of-kind procs, and fall back to brief 2–4-frame compact impacts for concurrent triggers. Critical enemy telegraphs retain their priority. Screenshake optional <=2 px and 80 ms, off for reduced motion. Strong visual beats should not hide the entire path or obscure enemy HP bars for over 250 ms. Scale giant effects as layered transparent imagery, NOT higher true attack hitboxes.

ATLAS NOTATION
A sheet can have named groups packed in rows (e.g. row A 1x8 256-square cells; row B 1x6 192-square cells). Maintain JSON specifying each region, pivot, cell rect, duration and hierarchy. Use the names in the ASSET line as group identifiers. Prompts all end implicitly with: 'polished top-down cartoon sci-fi tower-defense VFX matching my exact turret-head reference; strong clean outlines, carefully separated frames, flat solid magenta #FF00FF background, no text, no grid lines.'

BUDGET AND ACCESSIBILITY
- Prefer 192–256 px square source cells for high-impact illustrations; for 60–100 px displayed effects, 128px can suffice. Do not blindly allocate full 2048² atlases to every tiny aura. Pack each unique character/sheet into efficient WebP/PNG atlas only after the authored-magenta source is chroma-keyed; retain original editable sources.
- Limit 1 large 256px-class animation + <=6 small actor sprites simultaneously per side in heavy waves; reuse sprite pools. If many procs occur, select deterministic compressed animation instead of queueing 2 seconds of delays. A 1.5s signature should not block player interaction.
- Use distinct shape/motion as well as colors: hand/grab, crown/stamp, wolf/jaw, dragon/dive, clock/rewind, door/reflect, hive/sacrifice. Colorblind users and small screens should still identify the gameplay cue. Support reduced-motion: 1–2 held PNG impact frames, no camera movement, same gameplay.

CO-OP and PVP remote events should use authoritative actor IDs and snapshots. Do not animate star increases/decreases on the wrong unit or nonexistent protected target.
