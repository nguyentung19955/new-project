# B — Chỉ số đồ, nâng cấp, ép đồ, kinh tế (đọc CHUNG.md trước)

1. Bảng chỉ số mọi món đồ (vũ khí, áo, mũ, giày, phụ kiện… theo `js/data.js`) ở mỗi bậc (Trắng → Rực lửa) và mỗi cấp mài: Sức mạnh đóng góp, so sánh món cùng ô — món nào trội tuyệt đối / vô dụng.
2. Ép đồ 7 bậc + dòng hiệu ứng ngẫu nhiên: giá (đá, vàng, quặng) so với lượng rơi / ngày; bot mất bao nhiêu ngày để lên Tím / Vàng / Đỏ; dòng nào quá mạnh / vô dụng.
3. Kinh tế vàng / quặng / đá: thu mỗi ải, ải ngày, Bà Hàng Xén (quặng 40 vàng, 15/ngày — đang chờ quyết); có tắc nghẽn hay dư thừa.
4. Bộ trang phục / skill bộ (Rừng, Biển, Lâu đài, Ninja): lực chiến bộ so với đồ lẻ, skill bộ lên trùm.
5. Đề xuất số cụ thể.
