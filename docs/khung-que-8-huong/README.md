# Khung người đặc (nhìn ngang, quay phải)

Bản 8 hướng đã bỏ (16/10, chủ game: "không cần 8 hướng"). Chỉ còn:
- `nguoi-dac/`: khung người đặc tô màu (cam = tay phải, vàng = chân phải, tím = tay trái, xanh = chân trái, vạch đỏ = vũ khí) cho chạy, kiếm 1–3, búa nện; script `ve-chay-chuan.py`, `ve-tu-the.py`, `ve-bua.py`.
- `mau/`: ảnh mẫu Cu Tí gửi kèm prompt.
