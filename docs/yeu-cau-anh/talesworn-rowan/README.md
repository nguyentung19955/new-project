# Ảnh cần gen thêm cho Rowan (không gấp — Rowan đã chạy được bằng cách ghép đầu)

Rowan hiện tại = thân bộ ninja đổi màu + đầu mũ trùm cắt từ ảnh ChatGPT `rowan-4-goc-nguon-chatgpt.png`.
Đạt ở đứng / đi / chạy / chém / thương / búa / chết. Còn yếu ở **3 chỗ** dưới đây. Mỗi prompt dán vào ChatGPT, tải ảnh về để vào thư mục này
đúng tên tệp, phiên sau sẽ cắt và ghép bằng `docs/anh-goc/zed/trang-phuc/bo-5-rowan/dung-rowan.py`.

## 1. `rowan-dau-lon.png` — đầu khi lộn tròn (né)
Hiện tại: lúc cuộn tròn chỉ đổi tóc đen thành màu mũ, nhìn hơi giống tóc vàng dựng (3 khung, 0,27 giây).

```
Pixel-art game sprite sheet, 4 small heads of the same character in one row: a young fairytale blacksmith apprentice wearing a large saffron (#E0A23A) hood with darker rim (#A86A22), chestnut hair. Views: (1) head tucked down seen from above-back while rolling forward, (2) same rotated 90 degrees, (3) same rotated 180 degrees, (4) same rotated 270 degrees. Each head about 32x28 pixels, 1px dark outline #18202A, crisp hand-placed pixels, limited palette, evenly spaced, flat solid magenta #FF00FF background, no blur, no text, no shadows.
```

## 2. `rowan-dau-8-huong.png` — đầu 8 hướng cùng cỡ
Hiện tại mọi khung dùng một góc 3/4 trước-phải (khung quay lưng dùng góc sau). Có đủ hướng thì đầu theo thân khi vặn người / ngửa đầu lúc trúng đòn.

Directions: front, front-right 3/4, right, back-right 3/4, back, back-left 3/4, left, front-left 3/4. Each head about 32x28 pixels, 1px outline #18202A, crisp limited palette, flat solid magenta #FF00FF background, no blur, no text, no shadows.
```

Each about 28x12 pixels, 1px outline #18202A, crisp limited palette, flat solid magenta #FF00FF background, no blur, no text, no shadows.
```
