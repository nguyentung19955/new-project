# Trang phục Zed
- Mỗi bộ = nguyên bộ 27 tấm động tác Zed mặc sẵn bộ đó (không ghép lớp). Màu nhuộm bằng code là biến thể bổ sung.
- Mỗi vùng có 1 bộ đặc trưng để mở khoá, mặc được ở mọi vùng.
- Cách gen: SỬA từng tấm động tác đã có (giữ y tư thế, chỉ thay đồ) → neo vũ khí trong gan-vk/neo.json dùng lại được.
- Bộ 1: ninja đen–đỏ (hiện có). Bộ 2: Rừng, xanh rêu–nâu đất–vàng đất. Bộ 3: Biển, xanh lam–trắng (chưa làm).
