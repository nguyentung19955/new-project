# TURRET MERGE

Game merge tower-defense cho điện thoại (kiểu DCDW / Lucky Defense): xây bộ 5 thẻ, triệu hồi ụ súng lên bàn, kéo ghép 2 ụ cùng loại cùng sao để lên sao, giữ đường trước quái và 12 trùm. Chế độ SOLO / CO-OP / PVP / ONLINE.

- Mã game: [`thap/`](thap/) — mở `thap/index.html` (thêm `?mode=solo&notut=1` để vào trận nhanh).
- Chơi thử: https://nguyentung19955.github.io/new-project/thap/ · https://turret-merge.web.app
