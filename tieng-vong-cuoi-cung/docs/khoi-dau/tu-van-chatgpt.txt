0. QUYẾT ĐỊNH CHÍNH
- ONE title screen, ONE global save, ONE unified pause menu, ZERO region-specific start menus.
- First play: open link -> (rotate/audio gate if needed) -> illustrated title -> NEW GAME -> short skippable opening
  -> Bell Village -> first touch movement in a safe space -> talk to one NPC / inspect Rootbound Bell -> Region 1 directly
  -> learn attack + jump in first Region 1 rooms.
- Return: title -> CONTINUE -> exact last safe spawn/checkpoint (not just "last region").
- Bell Village = narrative + spatial hub. Region 1/2 are destinations inside one game. Keep boss-room gate R1->R2 and Rootbound Bell fast travel.
- Do not make account, cloud merge, multi-step setup or long cutscene a prerequisite to swinging the sword.
- If only 3 changes ship this week: (1) real New Game / Continue title replaces launcher, (2) remove region page menus,
  (3) sign-in / cloud-conflict prompts never block guest first play.

1. ĐỌC ẢNH CHỤP
- Main page: developer-launcher look, first-timer can't find the canonical start; Region 2 locked = premature info; Demo Room visible.
- Region menu panel (purple + antique gold + skull) = good UI material; reuse as pause/settings/save panel, NOT a second launch gate.
- Bell Village = strongest visual identity (giant cracked bell, hanging bells, warm windows) -> base title art on it.

2. P0 — FIRST LAUNCH, TỪNG BƯỚC
State machine: BOOT -> DEVICE CHECK -> TITLE -> NEW GAME/CONTINUE -> OPENING -> VILLAGE (or saved world).
Village: Rootbound Bell -> destination -> transition -> region gameplay. R1 boss gate -> transition -> R2. Any gameplay: PAUSE -> Return to Title.
No scene transition passes through another menu. All scenes use one save manager + shared global UI.
00 Show local loading splash immediately (not raw HTML text); preload title art, font, primary controls.
01 Portrait -> minimal "Rotate to Play" screen (recommendation, not dead end; Safari can't lock orientation).
02 Title with main CTA NEW GAME. No modal sign-in. First tap unlocks audio; never autoplay music before a gesture.
   No "Press to start" in v1.
03 NEW GAME: no save -> start immediately, no slot chooser. Save exists -> confirm "Start a new journey? Your current journey will be replaced on this device." CANCEL / START NEW (+ optional back up).
04 Opening "The First Silence": ideally 2–3 essential panels (<20 s), tap to advance, SKIP visible from panel 1. 7-panel version OK if skippable; never replay; set introSeen on skip.
05 Spawn Bell Village screen 1, safe spot near Vesper / clear route to Rootbound Bell. Movement control visible; one hint "Drag to move" (tiny thumb animation) until first move.
06 First control here, before any dialogue. Guide by light / NPC head-turn / bell shimmer, not a quest panel.
07 TALK icon appears only near NPC; optional. One-line objective after first move: "Find the Rootbound Bell."
08 Rootbound Bell destination sheet: "Weeping Heartwood — Enter", locked "Rotting Roots — Defeat the Hollow Bell Mother". Village itself not listed. One tap -> transition -> Region 1 room 1. No second menu.
09 Region 1 room 1: teach jump + attack via geometry and an easy enemy; dash only after acquired; heal at first damage when a charge exists. Early first Rest Bell.
10 After first Rest Bell: tiny "Progress saved". Never force account linking.
Target: NEW GAME -> first movement ~10–25 s (few seconds if intro skipped). If players can't find the bell in ~1 min, shorten route.
Return cases: A local save -> CONTINUE primary + status "Weeping Heartwood · Rest Bell 03" + save age. C cleared storage -> NEW GAME primary, discreet ACCOUNT / RECOVER SAVE.
D cloud vs local differ -> title loads first, small "Two saves found — Review" badge; resolve before Continue commits; never delete the other without backup.
E auth expired -> keep playing locally, small sync status.

4. P0 — SAVE / ACCOUNT / CLOUD
- One versioned global save: saveId, schemaVersion, playerId, lastSafeSceneId, lastSafeSpawnId, current scene/transition checkpoint, introSeen + quest flags,
  region 1/2 bosses + doors + pickups, HP/maxHP, Echo Shards, Lattice/charms, abilities (Root Anchor), map reveal, playtime, updatedAt, cloudRevision, localRevision.
- Migrate old per-region saves once, keep backup until verified.
- P0 one "Journey" only; P1 maybe 2–3 slots later.
- Commit points: Rest Bell (atomic), village entry/exit, boss clear (immediately), R1->R2 gate (boss defeated + gate open + destination spawn as one checkpoint), Return to Title. Never say "Saved" before write succeeds.
- Cloud: guest first. Account lives in OPTIONS > ACCOUNT / CLOUD SAVE + small title icon. States: Guest · On-device save / Signed in · Synced / Syncing… / Offline · Saved on device / Action needed · Choose a save / Sync failed · Retry.
- Conflict modal: "Two journeys were found"; cards THIS DEVICE vs CLOUD (timestamp, location, playtime, bosses); "Use this device" / "Use cloud" / "Not now"; note "Your other save will be kept as a recovery copy first." Backup before replace; don't rely on timestamps alone.
- Export/Import: P1 under OPTIONS > SAVE DATA only.

5. P0 — REGION TRANSITIONS
- Remove Region 1 / Region 2 / Demo Room from public title (Demo -> debug only).
- Region pages show NO Continue/New Game/Sign-in/Import panel. Read global save + transition intent, preload, then gameplay.
  P0 OK to keep separate HTML pages but share one global state; suppress the extra menu; survive reload/back.
